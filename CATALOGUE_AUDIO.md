# Catalogue des audios — La Citadelle

Inventaire des lecteurs audio trouvés dans les archives annuelles, l’accueil et les pages de thème. Les titres sont transcrits depuis le texte HTML ou les pochettes quand celles-ci sont lisibles. Les noms de fichiers sont ceux du dossier `audio/` (sauf flux externe). Les erreurs de transcription visibles sur la pochette sont conservées autant que possible, avec une note si utile.

> **Note de lecture :** certaines pochettes sont absentes du dépôt ou indiquent une date différente du nom audio. Ces cas sont signalés plutôt que devinés. Les lignes marquées « titre à relever » restent à compléter.

## Points à contrôler

- **Chemins de l’accueil** : les lecteurs d’accueil utilisent `../audio/…`, alors que `index.html` est à la racine. Les fichiers existent sous `audio/`; le chemin HTML devrait probablement être `audio/…`.
- **Pochettes absentes** : `pochette culte Replay13112022.jpg` est référencée mais n’existe pas dans `image/`; le titre correspondant reste à identifier.
- **Fautes dans les noms audio** : le dépôt contient des noms `cule…` pour le 03/04/2022 et le 11/12/2022, ainsi que `Exortation` au lieu de `Exhortation` pour plusieurs exhortations. J’ai lié les chemins locaux tels qu’ils existent.
- **Écarts de dates imprimées** : plusieurs pochettes d’exhortation indiquent 2021 alors que le fichier audio est daté 2022; le 09/10/2022 a une pochette du 10/10; le fichier audio du 23/01/2022 est associé à une pochette du 26/01. Voir les notes dans la colonne Source.
- **Entrées incomplètes** : la pochette du 02/10/2022 est lisible et le titre est saisi; celles du 13/11/2022 et certains fichiers d’exhortation dont la pochette est absente ou ne porte pas de titre nécessitent un contrôle manuel complémentaire.
- Les liens audio pointent vers les fichiers relatifs au dépôt. Ce catalogue n’embarque pas les médias ni ne garantit la lecture si un fichier a été supprimé.
